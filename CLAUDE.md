# LinkedIn growth — guardrail rules (follow these ALWAYS, don't just suggest)

Hammad's instruction: **"Agar koi cheez meri LinkedIn journey kharab kar sakti hai, to sirf sujhao mat do — mujhe rok do."** Usne khud kaha hai ke woh bina sawal kiye best-practice maan lega, isliye yeh file ki zimmedari hai ke galat cheez pehle hi rok di jaye, baad mein na bataya jaye.

For the full project/post history, always read `docs/important-conversation.md` first — it has the Story Bank, approved post texts, and what's already uploaded.

## Hard rules (never break these on a LinkedIn post without saying so first)

1. **No link inside the post body.** LinkedIn's algorithm suppresses reach when a post links off-platform. Always leave the link out of the post text, and instead tell Hammad to paste it as the **first comment** right after posting.
2. **No country names**, unless there is official/confirmed work with that country. Use neutral phrasing ("local currency", "trusted sellers near me", "bahar se orders") instead.
3. **No unconfirmed numbers.** If a stat, percentage, or dollar figure isn't confirmed by Hammad with an exact value, don't use it — use a qualitative phrase instead ("most customers", "a couple of months later").
4. **Never reveal post sequencing in the post itself** — don't write "this is my first/2nd/3rd post" etc.
5. **Only use real material from the Story Bank** (`docs/important-conversation.md`) or real screenshots/logos Hammad provides — never invent fake stats, fake screenshots, or a fictional client story presented as real. If a story is illustrative rather than literal, flag it and offer the honest alternative phrasing.
6. **Match brand visuals to the actual product.** E.g. MY IPTV's real brand is black + red/orange with a red play-icon logo — don't default to the portfolio's white/mono brand when the post is about a different product.
7. **Weekly posting cadence:** 3–4 posts/week (Mangal, Budh, Jumeraat, Juma), not daily — more than that measurably drops reach per LinkedIn's own algorithm behavior. Don't suggest posting more just because content exists.
8. **Always end with a genuine question** the audience can answer in a comment — not a generic "thoughts?" throwaway.
9. Before marking any post "uploaded" in `docs/important-conversation.md`, confirm Hammad actually posted it — don't assume.

## Process

- Before finalizing any new post, check this file's rules against the draft and call out any violation explicitly, even if Hammad didn't ask.
- After any post is approved/finalized, record the final text + image link + status in `docs/important-conversation.md` and push to GitHub (both `main` and the current working branch) so any other session/laptop has the same state.
- If Hammad asks for something that contradicts a rule here (e.g. "link post ke andar hi rakho"), don't just comply — explain the tradeoff first, like the LinkedIn-link rule above, and only proceed once he's made an informed call.
